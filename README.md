# tah-game

**Dead Fields** — an agriculture-themed Dead Cells riff. A single hand-built farm level: run, jump (double-jump included), dodge-roll, and fight your way through crows and boars to reach the barn. Collect corn for points — gather enough and you transform into a combine harvester that can't jump but plows straight through enemies on contact. Low-res canvas (320x180, bright Terraria-style pixel art, scaled up with pixelated rendering), no assets, no build step.

Play: https://thataaronguy-sunstream.github.io/tah-game/

**Controls:** `A`/`D` move, `W` jump (works twice in the air), `Space` attack (2-hit combo), `Shift` dodge-roll (i-frames).
